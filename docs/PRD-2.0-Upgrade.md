# China OS 2.0 系统升级与全维度提升 PRD

> **1.0 版本封板** · **2.0 升级规划**  
> 文档版本：v1.0  
> 更新日期：2026-02

---

## 一、1.0 版本基线总结

### 1.1 已交付能力

| 模块 | 子模块 | 状态 |
|------|--------|------|
| **系统架构** | Dashboard、HAL、Kernel、Telemetry、BIOS、Network、Event Log、Analysis | ✅ |
| **数据与文档** | 数据集成(v2026)、本地文档库(WB) | ✅ |
| **深度透视** | 红色巨网、军事力量、科技发展、大国外交、海外资源、央地关系 | ✅ |

### 1.2 技术栈现状

- **前端**：单页应用 (china.html)，Tailwind CSS + Chart.js + Plotly
- **数据**：世界银行 CSV (wb_api_chn.csv)、目录索引 (wb_catalog.json)
- **脚本**：build_wb_catalog.py（目录构建）
- **交互**：分组下拉导航、详情页筛选、暗色模式、数据信任滑块

### 1.3 已知局限

- 单体 HTML 体量过大（约 4000+ 行）
- 数据源单一，无实时更新
- 图表与模块强耦合，难以复用
- 无持久化、无用户态（收藏/笔记）
- 无国际化、无障碍支持薄弱

## 三、全维度升级规划

### 3.1 系统架构升级

#### 3.1.1 前端工程化

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **框架选型** | 从单体 HTML 迁移至 React/Vue + Vite | 支持按需加载，首屏 < 3s |
| **模块拆分** | 按 navGroups 拆分为独立路由与组件 | 单模块可独立开发、测试 |
| **状态管理** | 引入 Zustand/Pinia 统一管理 appData、state、charts | 无全局变量污染 |
| **设计系统** | 抽离 os-card、chart-container、nav-dropdown 为可复用组件 | 支持主题变量与暗色模式 |

#### 3.1.2 数据总线升级

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **DataBus 2.0** | 统一 NBS、WB、IMF、自定义 CSV 的接入协议 | 支持 schema 校验、缓存策略 |
| **增量更新** | 支持按指标、按年份增量拉取 | 减少全量加载，支持离线兜底 |
| **审计对账** | 多源数据对比视图（如 NBS vs WB GDP 差异） | 自动标记异常偏差 |

#### 3.1.3 插件与扩展

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **深度透视插件化** | 每个 Depth 模块可独立注册、懒加载 | 新增模块无需修改主框架 |
| **图表插件** | 支持注册自定义 Chart 类型（如桑基图、地理热力） | 与 Chart.js 解耦，可切换 ECharts/D3 |

---

### 3.2 数据能力升级

#### 3.2.1 数据源拓展

| 数据源 | 接入方式 | 用途 |
|--------|----------|------|
| **NBS 国家统计局** | API/爬虫/手动导入 | 实时宏观指标、地区数据 |
| **IMF WEO** | API/CSV 导入 | 全球对标、预测数据 |
| **海关总署** | CSV 导入 | 贸易结构、资源依赖 |
| **地方债数据** | 公开披露/爬虫 | 债务热力图、风险预警 |
| **WB 扩展** | 多国家、多指标 | 全球共识对比仪表盘 |

#### 3.2.2 数据治理

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **指标目录 2.0** | 支持分类、标签、单位、数据源溯源 | 可搜索、可筛选 |
| **时间轴统一** | 统一处理 1960–2050 年跨段 | 支持模拟/预测数据标注 |
| **缺失值策略** | 插值、填充、显式标注 | 图表展示时明确区分 |

---

### 3.3 交互与体验升级

#### 3.3.1 响应式与性能

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **移动端适配** | 导航折叠、图表横滑、卡片堆叠 | 小屏可用性 > 90% |
| **虚拟滚动** | 长列表（如 WB 1513 指标）分页/虚拟化 | 滚动帧率 > 55fps |
| **图表懒加载** | 进入视口再初始化 Chart | 首屏图表 < 5 个 |

#### 3.3.2 无障碍 (a11y)

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **键盘导航** | 支持 Tab 切换、Enter 激活 | 通过 WCAG 2.1 AA |
| **屏幕阅读器** | 图表 aria-label、数据表格语义化 | 可理解核心数据 |
| **对比度** | 暗色模式与亮色模式对比度达标 | 文字对比 ≥ 4.5:1 |

#### 3.3.3 国际化 (i18n)

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **中英切换** | 导航、标签、说明文字 | 支持 zh-CN / en |
| **数据单位** | 亿元/万亿、% 等按语言格式化 | 无硬编码单位 |

### 3.4 可视化升级

#### 3.4.1 统一图表库

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **图表配置标准化** | 统一 theme、legend、tooltip、响应式 | 一套配置多端复用 |

| **雷达图增强** | 多维度对标（中/美/日等） |

#### 3.4.3 地图能力

| 项目 | 描述 | 验收标准 |
|------|------|----------|
| **中国省级地图** | 支持点击、悬停、钻取 | 可切换指标 |

## 四、技术栈建议

| 领域 | 1.0 | 2.0 建议 |
|------|-----|----------|
| **框架** | 原生 HTML/JS | React 18 + TypeScript + Vite |
| **状态** | 全局变量 | Zustand / Jotai |
| **路由** | 自定义 switchTab | React Router v6 |
| **图表** | Chart.js + Plotly | Chart.js + ECharts + D3（按需） |
| **地图** | 无 | Leaflet / Mapbox GL（或 ECharts 地图） |
| **样式** | Tailwind CDN | Tailwind + PostCSS |
| **构建** | 无 | Vite + 代码分割 |
| **测试** | 无 | Vitest + Playwright |
| **CI** | 无 | GitHub Actions |

## 六、风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 重构导致 1.0 功能回退 | 建立 E2E 回归用例，关键路径自动化 |
| 数据源 API 不稳定 | 本地缓存 + 兜底 CSV，明确数据新鲜度 |
| 图表性能在低端设备卡顿 | 按设备能力降级（简化动画、减少数据点） |
| 多源数据口径不一致 | 建立指标映射表，审计视图显式标注差异 |
