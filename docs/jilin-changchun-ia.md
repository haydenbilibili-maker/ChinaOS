## 定位

以 2026-07-22 长春市委常委会扩大会议暨上半年高质量发展讲评会为**事件锚点**，穿透「前所未有的困难和挑战」官方表述与自媒体「七重崩盘」口号，用**三层证据台账**（官方表述 / 可核实统计 / 评论演绎）解析长春—吉林结构约束。

## 信息架构

1. **事件锚点** — 会议、人物、原话、下半年部署关键词
2. **关键读数仪表盘** — 仅展示已核验进度/年报数字
3. **七维压力台账** — 官方可核实 vs 评论演绎分栏（禁止把评论数字写成事实）
4. **汽车/一汽产业链** — 集团销量公开报道 vs 属地产销承压
5. **财政与土地** — 一般公共预算缺口 + 政府性基金/土出让
6. **人口与首位度** — 自然减少 + GDP 省内份额 ~53.5%
7. **下半年应对与未决项** — 已兑现 / 进行中 / 未决
8. **出处脚注**

## 证据分层铁律

| 层 | 含义 | 呈现 |
|----|------|------|
| ①官方表述 | 会议通稿原话与部署 | 引用块 + 来源链 |
| ②可核实统计 | 统计局/财政局/省公报 | 仪表盘、图表、台账「核实」列 |
| ③评论演绎 | 自媒体「崩盘」叙事与未核验数字 | 台账「评论口径」列，标红/存疑 |
