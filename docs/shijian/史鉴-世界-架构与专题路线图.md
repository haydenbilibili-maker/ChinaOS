```

│   ├── 中华·总论 / 方法论 / 周期机制 / 案例库 / 古今对照
│   └── 真源：docs/shijian/*（v1.0 封板）

    └── 世界·专题（SJW-01+）

```

| 线 | 编号 | 静态资源 | React 路由前缀 | 皮肤令牌 |
|---|---|---|---|---|
| 中华 | `SJ-XX` | `app/public/shijian/` | `/modules/shijian` | `--sj-*`（宣纸史册，冻结） |
| 世界 | `SJW-XX` | `app/public/shijian-world/` | `/modules/shijian-world` | `--sjw-*`（同色义、偏冷墨底；见 §2） |

**交叉原则**：中华线 ↔ 世界线可深链；与「三体」模块可交叉「文明博弈」，但强制标注——**史鉴 = 历史机制台账**，**三体 = 思想实验透镜**，动力学命名不合并。与 `/deterrence` 交叉时：**史鉴 = 冷战编年机制史**，**威慑模块 = 谢林工具箱**，职责不合并。与 `/thucydides`：**权力转移窗口可对照**，英美/霸权/德国案强制关键差异（同谱系合作转移 ≠ 大陆挑战者 ≠ 通用修昔底德常数）。与 `/energy`：**SJW-18 = 气候—能源基座机制史**，**SJW-21 = 石油中东落地案**，**能源模块 = 当代压舱石工具箱**，职责不合并。

## 1. 方法论裁定（默认采用 · 待架构师可推翻）

### 1.1 默认方案（本轮落地）

| 元件 | 裁定 | 说明 |
|---|---|---|
| **史鉴引擎·四步法** | **复用** | Structure → Cycle → Mechanism → Mirror；产物仍为可比台账 |
| **台账七字段** | **复用** | 一句话拐点 / 结构切片 / 相位定位 / 五力（可配置轴）归因 / 史家交锋 / 成败三列 / 古今·中西映射双栏 |
| **关键差异** | **强制** | 每处映射必须「相似机制 + 关键差异」；禁裸类比 |
| **五力衰变模型（中国王朝版）** | **不硬套** | 世界线采用 **可配置五轴**（下称「帝国/文明五轴」），色义仍对齐 SJ：财政=`ochre` / 精英=`celadon` / 合法性=`paper` / 军事边疆=`vermil` / 基座=`ink·次级` |

### 1.2 帝国/文明五轴（可配置默认）

世界线默认轴（可按专题覆盖标签，不可改色义）：

1. **财政—资源汲取**（tax / credit / energy / trade surplus）  
2. **精英—组织循环**（bureaucracy / party / capital elite / officer corps）  
3. **合法性—叙事**（divine right / nationalism / ideology / performance）  
4. **军事—地缘压力**（frontier / alliance / naval / nuclear）  
5. **生态—人口—技术基座**（demography / productivity / science base）

专题卷可在页眉声明「本卷轴标签变体」，但交互与色义不得另起一套。

### 1.3 备选（未采用 · 待裁定）

若架构师认为世界史不宜沿用「史鉴引擎」品牌：可另立「世界史鉴·四步」命名，字段同构。**本轮不实施**，以免双方法论分叉。

## 10. 质量门（世界线）

1. Hub 可导航至全部已建专题；中华线 / 三体 / deterrence / energy 入口可见。  
2. 每卷有签名视觉 + 七字段意识（矩阵卷可用 SJ-07 式，不硬套单案交互切片）。  
3. 映射双栏齐全；与三体/威慑/能源交叉处标明透镜边界。  
4. `npm run build` 通过；`check:shijian` 中华线 0 回归。  
5. 不臆造数字；争议标〔存疑〕。  
6. 台湾对照卷：机制台账 only；禁止统战话术/煽动。
