# 史鉴系列 · 签名视觉规格书(Signature Visual Spec v0.1)

> 每个 SJ 模块"先视觉后正文"。本规格书把母本机制翻译成可直接开画的 SVG 结构:编码何种张力、画布与几何、数据→视觉映射、令牌用法、交互、响应式与可达、以及禁止项。执行模型据此画,不做二次设计决策;有异议先提出。
>
> 通用约定:纯内联 SVG,`viewBox` 坐标系,零外链;所有色值走 `chinaos-shijian.mdc` 的 `--sj-*` 令牌;`prefers-reduced-motion` 下停用动画;交互元素 `tabindex="0"` + `:focus-visible` 描边;≤768px 降级方案见各图。
>
> **案例卷 §02 结构切片**（SJ-05+ 单案台账）另有专项几何真源：[结构切片几何规格.md](./结构切片几何规格.md)——类型→母题映射、已定案四案几何、禁止竖轴克隆。本规格书的色义/卷轴/朱批/交互约定仍适用。

## 通用视觉母题(四图共用)

- **卷轴皮肤**:主图外框以极简卷轴母题包裹——左右两端各一条竖向"轴头"(1–2px 双线 + 赭金 `--sj-ochre` 描边),中段为展开的宣纸面(`--sj-paper` 极低透明度纹理,用 SVG `<pattern>` 做细横纹,不用位图)。
- **朱批**:关键标注用朱红 `--sj-vermil`,取"圈点+旁注"形态(小圆圈 + 引线 + 短注),不喧宾夺主。
- **色义固定**(全系列一致,务必统一):
  - 财政汲取力 = 赭金 `--sj-ochre`
  - 精英循环力 = 青瓷 `--sj-celadon`
  - 合法性叙事力 = 宣纸白 `--sj-paper-100`
  - 边疆—军事力 = 朱红 `--sj-vermil`
  - 生态—人口基座 = 深墨 `--sj-ink` 系(作底/包络)
- **相位色阶**(五相位统一):上升=青瓷渐亮 / 鼎盛=赭金 / 僵化=灰褐(`--sj-paper-300` 压暗)/ 崩解=朱红 / 重整=青瓷复现。

## 图 A · SJ-00「治乱循环总螺旋图」

**编码张力**:两千年治乱循环——重复而不闭合(每圈回到低水平均衡,但技术—制度天花板不变),末端接当代锚点。

**画布**:`viewBox="0 0 900 900"`,方形,中心 (450,450)。

**几何结构**:
- 一条**对数螺旋**由内向外展开约 3.5–4 圈(阿基米德螺旋亦可,但对数螺旋更能表达"每圈尺度放大但结构自相似",呼应超稳定结构)。用 `<path>` 分段绘制,便于分段着色。
- 螺旋按朝代分段:秦汉 → 魏晋南北朝(分裂段)→ 隋唐 → 五代(分裂段)→ 宋 → 元 → 明 → 清 → 〔末端〕当代锚点。**分裂段用虚线或断续笔触**与大一统段(实线)区分——直接对应母本"分裂=失衡态"。
- 每段按其主导相位上色(相位色阶);盛世点(文景/开元/康乾)用赭金小节点 + 朱批圈点标"隐性拐点"。
- 螺旋末端(最外圈开口处)一枚**当代锚点**:略大的青瓷/朱红双色节点,引线朱批注"当代:相位待定 → 见 SJ-04"。

**数据→视觉映射**:
- 半径 = 时间(内古外今);角度位置 = 朝代序列;段色 = 该期主导相位;节点大小 = 该拐点的历史权重。

**交互**:
- 悬停/聚焦某朝代段 → 高亮该段 + 侧栏弹出一句话相位定位(数据来自母本相位盘)。
- 点击盛世节点 → 朱批展开"盛极即拐点"注解。
- 移动端:去掉悬停,改为点击;螺旋可缩为 2.5 圈简版。

**禁止**:不要画成闭合圆环(会误示"循环回到原点");必须螺旋外扩以表达"重启而不升级"。

## 图 B · SJ-01「史家方法光谱图」

**编码张力**:史学方法没有高下,只有镜头差异与盲区——把各家定位到方法坐标系,让"选镜头"本身可视化。

**画布**:`viewBox="0 0 800 640"`,横向。

**几何结构**:
- 二维坐标系(不画粗重坐标轴,用极淡 `--sj-line` 网格):
  - **横轴**:左=考据实证 ←——→ 右=义理诠释。
  - **纵轴**:下=微观个案 ←——→ 上=长时段/系统。
- 八个史家/学派定位为坐标点(建议位置,执行时按此摆放):
  - 李敖 → 左下(考据·个案/论战)
  - 钱穆 → 右中偏上(义理·文化生命)
  - 金观涛 → 右上(义理偏系统·长时段系统论)
  - 黄仁宇 → 中上(考据与义理之间·长时段)
  - 费正清 → 中(中外互动)
  - 加州学派(彭慕兰/柯文)→ 中偏考据·系统(经济史比较)
  - 孔飞力/魏斐德 → 左下偏中(微观权力个案)
  - 施坚雅 → 中下(区域/空间·偏实证个案-系统之间)
- 每点:一枚节点 + 姓名 + 极短方法标签。节点描边用青瓷,选中态填朱红。

**数据→视觉映射**:坐标位置 = 方法取向;点的"盲区"用一圈虚线弱光晕表示(愈大表示外推风险愈高,如金观涛系统论光晕较大)。

**交互**:
- 点击某点 → 右侧/朱批栏展开该家四栏卡片(核心方法·代表命题·适用场景·盲区风险,数据来自 SJ-01 正文)。
- 可选"研究问题"筛选器:选择问题类型(制度连续性/周期性/中外互动/区域差异/微观权力),高亮推荐的主镜头+补镜头组合。
- 移动端:坐标图上方改为可点列表,点选后滚动到卡片。

**禁止**:不要用大小/颜色暗示"谁更正确";光谱是并置,不是排名。

## 图 C · SJ-03「五力耦合力场图」(规律引擎核心视觉)

**编码张力**:五力不是并列清单,而是有向耦合——财政汲取力是枢纽,基座是承托一切的慢变量底盘。

**画布**:`viewBox="0 0 800 720"`。

**几何结构(分三层,自下而上)**:
1. **底盘层**:最下方一条厚重的深墨"基座"横带(生态—人口—技术),占底部约 1/5 高度,内嵌极淡的气候/人口波纹(慢变量=长波,用一条低频正弦暗纹)。所有上层力"坐"在其上。
2. **四力节点层**:上方四枚力节点,按色义固定上色:
   - **财政汲取力(赭金)置于视觉中心**——它是枢纽,尺寸略大,居中。
   - 精英循环力(青瓷)、边疆—军事力(朱红)、合法性叙事力(宣纸白)环绕财政节点三角/菱形布局。
3. **耦合有向边层**:节点间用**带箭头的曲线**表达耦合方向与强度(母本耦合图):
   - 基座 →(上推)→ 边疆压力 & 人口/流民(气候同步,用一条分叉箭头强调"同步")。
   - 边疆—军事力 → 财政汲取力(军费刚性,粗箭头)。
   - 财政汲取力 → 精英循环力(汲取触动特权,粗箭头,标"改革走钢丝")。
   - 精英循环力 → 合法性叙事力(党争内耗→绩效磨损)。
   - 合法性 → (回指)崩解出口。
   - 边权重 = 线宽;正/负耦合可用实线/朱红警示线区分。

**数据→视觉映射**:节点亮度/饱和 = 该力当前相位(可传参,供不同案例复用同一图);边宽 = 耦合强度;枢纽居中 = 财政力的传导地位。

**交互**:
- 点击任一力节点 → 高亮其所有出入边 + 朱批展开该力的机制/指标/衰变路径(来自母本第一部逐力解剖)。
- "衰变链演示"按钮:按母本主链顺序依次点亮 基座→边疆/人口→财政→精英→合法性→崩解,做一次链式高亮动画(`prefers-reduced-motion` 下改为静态编号)。
- 移动端:改竖排堆叠,边简化为编号箭头。

**禁止**:五力不可画成对称五边形等权并列(会抹掉"财政枢纽+基座底盘"的层级);必须体现有向、分层、不等权。

## 图 D · SJ-04「治乱相位罗盘」

**编码张力**:任一时点可被定位到五相位;鼎盛期是隐性拐点;系统能重启却不升级。

**画布**:`viewBox="0 0 720 720"`,方形,中心 (360,360)。

**几何结构**:
- 一个**五分环形罗盘**(非均分亦可,按相位停留时长配比):上升 / 鼎盛 / 僵化 / 崩解 / 重整,顺时针排列,各扇区用相位色阶着色。
- **鼎盛扇区**特殊处理:在其弧顶用朱批圈点标"隐性拐点",并让鼎盛→僵化的分界线画得比其它分界更"隐蔽/虚"——视觉上表达"拐点难以察觉"。
- 罗盘中心一枚**可旋转指针**(青瓷+赭金),指向当前定位的相位;指针尾部一小段引线注"当前:朝代/时点"。
- 环外一圈极淡刻度,每刻度可挂一个历史时点标记(供把多个案例定位到同一盘上对比)。
- 中心内圈嵌一行小字诊断:"超稳定结构修复力:强/中/弱 → 修复代价:回到低水平均衡"。

**数据→视觉映射**:指针角度 = 相位定位;扇区弧长 = 该相位典型停留时长;中心诊断 = 修复力评级。

**交互**:
- 拖动/键盘方向键旋转指针 → 切换相位 → 中心诊断与外圈说明随之更新。
- 点击外圈某历史时点标记 → 指针跳转到其相位 + 朱批展开该时点的五力签名(与图 C 联动:同一时点可在力场图上看五力状态)。
- 与 GY 接口:提供一枚"当代锚点"标记,点击注"当代定位见 GY-01 / 2026–2036 预测"。
- 移动端:罗盘缩小,指针改为下拉选择相位。

**禁止**:五扇区不要画成完全均分的对称饼图(会掩盖"鼎盛拐点隐蔽""各相位停留不等长");分界线须有强弱之别。

## 交付与联动

- 四图**色义与相位色阶必须全系列统一**(见通用母题),这是跨模块视觉一致性的硬约束。
- 图 C(力场)与图 D(罗盘)通过"同一时点"联动:罗盘定相位、力场看五力状态——这是规律引擎的双视图,建议 SJ-03/04 开发时共用一套数据结构(一个 JS 对象:`{时点, 相位, 五力评分[5], 修复力}`)。
- 每图先出**静态签名版**交架构师定调,确认后再加交互与联动。
- 执行顺序建议:图 C(五力力场,最能立刻反哺预测)→ 图 D(罗盘)→ 图 A(螺旋)→ 图 B(光谱)。
