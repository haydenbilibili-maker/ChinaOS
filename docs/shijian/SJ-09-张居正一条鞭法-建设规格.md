## 七字段（摘要）

① 明中后期边饷刚性下，一条鞭统合赋役重建汲取力；清丈触动士绅特权，张居正身后翻盘（人亡政息）。

② 结构切片：皇权万历 → 张居正纵列 → 清丈/一条鞭下行 → 士绅反弹回路。

③ 相位：僵化期中后段·改革窗口。

④ 五力：核心病灶财政汲取；死穴精英循环（清丈隐田）。

⑤ 史家交锋：李敖祛魅 / 钱穆 / 金观涛 / 黄仁宇数目字 / 汉学财政研究〔存疑〕。

⑥ 成败：已兑现短中期充盈；已失败人亡政息；未决〔反事实〕能否避免三饷越阈。

⑦ 古今映射：相似=汲取重建vs既得利益；差异=现代土地财政与数目字工具质变。
