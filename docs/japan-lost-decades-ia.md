# 中日比较·失去的三十年 · 模块 IA

> asOf 2026-09-28 · 路由 `/japan-lost-decades` · 分组 `region`（区域与全球化）· 侧栏紧邻「国际对标」

## 定位

以**阶段对位**方法比较日本 1985–2026（广场协议 → 泡沫破裂 → 坏账清算 → 通缩固化 → 安倍经济学 → 通缩退出）与中国 2005–2026（汇改 → 四万亿 → 去杠杆/贸易摩擦 → 地产转折 → 化债/反内卷），为中国当下发展阶段提供比较样本与政策意见。选址理由：数据密集、图表多，属经济类横向比较专题；与「国际对标」（静态横截面）互补，与经济大盘（中国侧当下切片）、史鉴·世界 SJW-15/16/23（日本历史卷）互设交叉链接。

## 信息架构

1. **总览** — 六项关键读数 · 双轴阶段卷轴（可点选阶段）· 四条核心结论 · 分维度「中国当下≈日本何时」· 相似度雷达（主观）· 学界争议并陈
2. **九维切片** — 宏观 / 产业 / 社会 / 贸易 / 金融 / 科技 / 教育 / 民生 / 人口；每维：对位折线（多指标切换）+ 关键数据表 + 日本/中国散文 + 相似机制·关键差异双栏 + 中国启示；支持 `?tab=slices&dim=<key>` 深链
3. **启示与意见** — 日本教训三列台账（已兑现/已失败/未决）· 可借鉴/需避免 · 结构性条件差异 · 日本化分叉三情景 + 观测清单 · 六条政策意见
4. **核验与出处** — 关键数据核验表（已核验/API 序列/约数/存疑）· 〔存疑〕清单 · 方法说明 · 出处

## 数据

- `seriesGenerated.js`：`node scripts/fetch-japan-lost-decades.mjs` 从世行 WDI（17 项）与 IMF DataMapper（8 项）抓取 1980–2025 中日年度序列，勿手改。
- `data.js`：阶段、切片文本、核验表与出处；手工数字均标口径与来源，无法核实者标〔存疑〕。

## 证据铁律

- 任何中日对照必须同时给出「相似机制」与「关键差异」，禁止裸类比。
- 口径冲突显式标注（如中国老龄化 NBS 15.9% vs 世行 14.9%；青年失业 NBS 16–24 不含在校生 vs ILO 15–24）。
- 学界争议并陈：失去的三十年是否成立（成立论 / 人口修正论 NBER w31914 / Hayashi-Prescott 供给侧 / 辜朝明·克鲁格曼需求侧）；2020s 日本是否走出。
- 相似度评分与情景为本模块主观研判，非统计指标、非预测。
