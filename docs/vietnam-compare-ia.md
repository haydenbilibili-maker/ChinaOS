# 中越比较研究 · 模块 IA

> asOf 2026-09-30 · 路由 `/vietnam-compare` · 分组 `region`（区域与全球化）· 侧栏紧随「中日比较·失去的三十年」

## 定位

以**阶段对位**方法比较越南 1976–2026（统一后计划经济 → 1986 革新 → 融入东盟/美越 BTA → 2007 入世 → 外资电子制造 → 公司债危机与「烧炉」→ 苏林时代精简机构）与中国 1976–2026（改革开放 → 南方谈话 → 入世 → 四万亿 → 新时代 → 地产转折/化债），回答两个问题：越南当下相当于中国哪一年；两国之间有哪些可以双向借鉴的机制与需要警惕的差异。

选址理由：与「中日比较」共用同一套方法（阶段对位 · 九维切片 · 三列台账），一个是前车（日本），一个是后来者（越南），放在一起便于对照；与国际对标（静态横截面）、经济大盘（中国侧当下切片）、中等收入陷阱、对外贸易、供应链、外交互设交叉链接。

## 对齐口径（可切换）

| 口径 | 原点 | 依据 |
|------|------|------|
| 改革起点 | 越 1986 ↔ 中 1978 | 越共六大「革新」/ 十一届三中全会 |
| 入世 | 越 2007 ↔ 中 2001 | WTO 正式成员日期 |
| 收入水平（默认） | 越 2025 ↔ 中 2015 | 世行 PPP 人均 GDP（2021 年不变价）：越 15,457 ≈ 中 2015.7 年水平 |
| 同日历年 | — | 同一外部环境下的绝对水平 |

分维度结论并不一致：现价美元人均 GDP 越南 2025 ≈ 中国 2010；城镇化 ≈ 中国 2001；农业就业占比 ≈ 中国 2018–19；65+ 占比 ≈ 中国 2012–13；研发强度低于中国 1996；贸易开放度无可比中国年份。

## 信息架构

1. **总览·阶段对位** — 六项关键读数 · 双轴阶段卷轴（可点选阶段）· 对齐曲线（收入口径下为「收入—增速」散点路径）· 五条核心结论 · 分维度「越南当下≈中国何时」· 相似度雷达（主观）· 学界争议并陈
2. **九维切片** — 宏观 / 政治体制 / 产业与外资 / 贸易 / 金融与地产 / 科技与教育 / 人口与民生 / 外交 / 转型模式；每维：对位折线（多指标切换）或专题图（机构精简幅度、三角贸易桑基图、PISA、全面战略伙伴时间线）+ 关键数据表 + 越南/中国散文 + 相似机制·关键差异双栏 + 中国启示；支持 `?tab=slices&dim=<key>` 深链
3. **双向启示** — 三列台账（已兑现/已失败/未决）· 越南对中国的反向启示 · 行业级竞争/互补台账 · 三情景 + 观测清单 · 政策意见
4. **核验与出处** — 关键数据核验表（已核验/API 序列/约数/存疑）· 〔存疑〕清单 · 方法说明 · 出处

## 数据

- `seriesGenerated.js`：`node scripts/fetch-vietnam-compare.mjs` 从世行 WDI（20 项）与 IMF DataMapper（6 项）抓取 1975–2025 中越年度序列，勿手改。IMF 接口需走 curl（Node fetch TLS 被拒）。
- `data.js`：阶段、切片文本、台账、核验表与出处；手工数字均标口径与来源，无法核实者标〔存疑〕。

## 证据铁律

- 任何中越对照必须同时给出「相似机制」与「关键差异」，禁止裸类比。
- 口径冲突显式标注：越南 NSO「全社会实现投资」vs 世行资本形成；FDI 注册 vs 实际到位 vs BoP；越南官方「公共债务」vs IMF 一般政府债务；人均 GDP 三口径（NSO / 世行 / IMF）。
- 纠正常见误读：越南 2026 年增速目标为 10% 以上（非 8%）；部委由 22 个减至 17 个（2025）；美国现行对越关税为 301 条款 12.5%（2026-07-24 起），IEEPA 关税已于 2026-02-24 终止。
- 政治维度保持中立：只陈述制度安排、人事与公开文件，不作价值评判；人事与反腐数字仅采官方公开口径。
- 相似度评分与情景为本模块主观研判，非统计指标、非预测。
