# China OS · VI 2.0「观象」视觉识别规范

> 版本 2.0 · 2026-10 · 适用于 `app/` 全部界面、导出物与 Worker 返回的错误页
> 代码落点：`app/src/styles/vi2/`（令牌、材质、动效、排版）· 样张页 `/#/design`

---

## 0. 一句话

**China OS 是一台观测中国的精密仪器。** 1.x 是「暗色网页 + 霓虹色块」，平、散、吵；2.0 要做成一件有材质、有刻度、有呼吸的器物：信息密度不降，但每一屏都有明确的主角、层次和光。

设计母题取自明代浑仪（armillary sphere）：同心环、刻度、铜、漆、星图。它对应产品的本质——多层观测环叠加在同一个对象上。

三个关键词：

| 关键词 | 含义 | 在界面上 |
| --- | --- | --- |
| 深 | 有材质、有景深，不是平面色块 | 漆面卡片、内高光、发丝边、颗粒、景深光晕 |
| 准 | 精密仪器的刻度感 | 刻度尺、等宽数字、对齐网格、指针式仪表 |
| 静 | 高密度但安静 | 一屏一个主角；强调色总量 ≤ 10%；只有告警才动 |

## 1. 色彩

### 1.1 基底

两套基底，均为暖调，避免 1.x 冷蓝灰的「后台系统感」。

| 令牌 | 夜览「玄漆」 | 日览「宣纸」 | 用途 |
| --- | --- | --- | --- |
| `--vi-bg-0` | `#07080B` | `#EEE9DF` | 页面最底层 |
| `--vi-bg-1` | `#0D0F14` | `#F5F1E8` | 主画布 |
| `--vi-bg-2` | `#14171F` | `#FBF8F2` | 卡片 |
| `--vi-bg-3` | `#1C202A` | `#FFFFFF` | 浮层、弹窗 |
| `--vi-ink-1` | `#EDE8DF` | `#16130F` | 主文字（暖白 / 墨黑） |
| `--vi-ink-2` | `#A29C91` | `#5A544B` | 次文字 |
| `--vi-ink-3` | `#8A847A` | `#736C61` | 辅助、刻度 |
| `--vi-line` | `rgba(237,232,223,.09)` | `rgba(22,19,15,.10)` | 发丝线 |
| `--vi-line-strong` | `rgba(237,232,223,.16)` | `rgba(22,19,15,.18)` | 分隔、边框 |

### 1.2 品牌色

| 名称 | 令牌 | 夜 | 日 | 角色 |
| --- | --- | --- | --- | --- |
| 朱砂 | `--vi-cinnabar` | `#E5483B` | `#C8322A` | 品牌主色、印章、告警 |
| 铜 | `--vi-brass` | `#D4A25A` | `#8A6224` | 刻度、仪表、关注 |
| 青瓷 | `--vi-celadon` | `#6FC2AE` | `#237561` | 稳定、正向 |
| 霁蓝 | `--vi-lapis` | `#6E8CFF` | `#3D5BD9` | 数据、链接、交互焦点 |
| 紫檀 | `--vi-rosewood` | `#B07CC6` | `#7C4C93` | 第五类数据（少用） |

所有文字色在对应卡片底上对比度 ≥ 4.5:1（已逐项核算）。

**用量**：基底 ≈ 70%，墨色文字 ≈ 20%，品牌色合计 ≤ 10%。一屏只允许一个「满色」强调元素，其他强调用 12–18% 透明度的底。

### 1.3 语义色（信号）

| 语义 | 颜色 | 形状 | 文字 |
| --- | --- | --- | --- |
| 稳 | 青瓷 | 圆 ● | 稳 / 正常 |
| 观 | 铜 | 菱 ◆ | 关注 |
| 警 | 朱砂 | 三角 ▲ | 承压 / 告警 |
| 未明 | `--vi-ink-3` | 空心圆 ○ | 待更新 |

颜色永远与形状、文字同时出现，色弱用户只看形状也能读懂。

### 1.4 数据可视化色板

有序 8 色，按顺序取用，相邻两色明度差 ≥ 15：
`霁蓝 → 铜 → 青瓷 → 朱砂 → 紫檀 → 石青 #4FA3C7 → 赭 #C07A4A → 墨灰 #8A8578`

连续色带：单向用「宣 → 朱砂」或「玄 → 铜」；双向（涨跌、偏离）用「青瓷 ↔ 中性 ↔ 朱砂」。

## 2. 字体与字号

### 2.1 字族

| 角色 | 中文 | 西文 / 数字 | 说明 |
| --- | --- | --- | --- |
| 标题 Display | Noto Serif SC 600/900 | Fraunces（可变，opsz） | 编辑部气质：页面主标题、阅读器标题、仪表大数 |
| 界面 UI | Noto Sans SC 400/500/600 | Inter（tnum、cv11） | 导航、按钮、正文段落、表格 |
| 数字 Figure | — | Inter tnum / Fraunces lining | 所有 KPI、表格数值一律等宽数字 |
| 代码 Mono | — | JetBrains Mono | **只**用于时间戳、编号、代码；1.x 的「满屏等宽」取消 |
| 阅读 Reading | Noto Serif SC 400/600 | Fraunces | 阅读器正文 |

字体栈（含国内系统字体兜底，Google Fonts 不可达时平滑降级）：

```css
--vi-font-display: 'Fraunces', 'Noto Serif SC', 'Songti SC', 'STSong', 'Source Han Serif SC', serif;
--vi-font-ui:      'Inter', 'Noto Sans SC', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', system-ui, sans-serif;
--vi-font-read:    'Noto Serif SC', 'Songti SC', 'STSong', 'Source Han Serif SC', Georgia, serif;
--vi-font-mono:    'JetBrains Mono', ui-monospace, SFMono-Regular, Menlo, monospace;
```

### 2.2 字号阶梯（流式）

以 `clamp(手机, 视口插值, 桌面)` 定义，390px 到 1440px 之间线性过渡。

| 令牌 | 手机 | 桌面 | 行高 | 字距 | 字族 / 字重 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| `--vi-fs-display` | 34 | 64 | 1.05 | −0.03em | Display 600 | 首页 / 样张主视觉 |
| `--vi-fs-h1` | 26 | 38 | 1.15 | −0.02em | Display 600 | 页面标题 |
| `--vi-fs-h2` | 20 | 26 | 1.25 | −0.01em | Display 600 | 区块标题 |
| `--vi-fs-h3` | 16 | 18 | 1.35 | 0 | UI 600 | 卡片标题 |
| `--vi-fs-body` | 15 | 15 | 1.65 | 0 | UI 400 | 界面正文 |
| `--vi-fs-small` | 13 | 13 | 1.55 | 0 | UI 400 | 说明、注释 |
| `--vi-fs-caption` | 11.5 | 12 | 1.4 | 0.04em | UI 500 | 标签、刻度、来源 |
| `--vi-fs-figure-xl` | 40 | 56 | 1 | −0.03em | Display 500 tnum | 主 KPI |
| `--vi-fs-figure` | 24 | 30 | 1.05 | −0.02em | UI 600 tnum | 次 KPI |
| `--vi-fs-read` | 17 | 19 | 1.9 | 0.01em | Read 400 | 阅读器正文 |

规则：

- 正文最小 15px，任何可读内容不低于 12px（1.x 大量 10px 文字取消）。
- 数字后的单位降一级字号、改次文字色：`4.6` + `%`。
- 中文段落使用 `text-wrap: pretty`，标题用 `balance`；标点挤压 `text-spacing-trim: trim-start`（支持的浏览器）。
- 英文大写标签（如 `DEFLATION & LIQUIDITY`）一律删去，改为中文眉题，避免装饰性噪声。

## 3. 栅格、断点与多端

### 3.1 断点

| 名称 | 宽度 | 栅格 | 边距 | 导航形态 |
| --- | --- | --- | --- | --- |
| `xs` 手机 | < 480 | 4 列 | 16 | 底部 Dock（5 项）+ 全屏命令面板 |
| `sm` 大屏手机 | 480–767 | 4 列 | 20 | 同上 |
| `md` 平板竖 | 768–1023 | 8 列 | 24 | 图标导轨（72px）+ 抽屉 |
| `lg` 笔记本 | 1024–1439 | 12 列 | 32 | 可折叠侧栏（264px） |
| `xl` 桌面 | 1440–1919 | 12 列 | 40 | 侧栏 + 右侧上下文面板（可开合） |
| `2xl` 大屏 | ≥ 1920 | 12 列，内容最大 1600 | 48 | 同上，看板可开「墙面模式」 |

### 3.2 多端规则

- **触控**：可点目标 ≥ 44×44px；手机上悬停效果改为按压反馈。
- **安全区**：Dock 与顶栏适配 `env(safe-area-inset-*)`。
- **表格**：手机上首列固定、横向滑动，并提供「卡片视图」切换。
- **图表**：手机上图例移到图下，隐藏次要坐标轴标签，tooltip 改为点按固定。
- **仪表盘**：KPI 栅格 6 → 3 → 2 列；手机上 KPI 改为横向滑动带，主视觉缩为一块。
- **方向**：平板横屏按 `lg` 处理。
- **验收**：每个页面在 390 / 768 / 1440 三档、日夜两主题下截图验收（CI 自动生成，见 `scripts/visual-snapshot.mjs`）。

## 4. 材质与层级

1.x 的问题是「每张卡片都一样平」。2.0 用五级层级区分主次：

| 层级 | 名称 | 材质 | 用于 |
| --- | --- | --- | --- |
| E0 | 画布 | 底色 + 极淡颗粒（2% 噪点）+ 经纬网格（只在看板） | 页面 |
| E1 | 漆面 | 自上而下 3% 亮度渐变 + 顶部 1px 内高光 + 发丝边 | 普通卡片 |
| E2 | 铜框 | E1 + 渐变描边（铜→透明）+ 柔和投影 | 主卡片、KPI |
| E3 | 琉璃 | 背景模糊 20px + 70% 不透明底 + 强投影 | 浮层、命令面板、抽屉 |
| E4 | 光 | 聚光（指针跟随的径向高光）+ 外辉光 | 悬停、聚焦、告警 |

**聚光边框**：E2 卡片在指针悬停时，以指针位置为圆心绘制 240px 径向高光，同时点亮边框对应区域。这是 2.0 最有辨识度的交互质感，代价低（纯 CSS 变量 + 一个 pointermove 监听）。

**氛围光**：页面背景有两到三团极慢漂移的光晕（朱砂、铜、霁蓝，透明度 ≤ 10%，周期 40–60s），只在 E0 层，减弱动效时静止。

圆角：控件 8、卡片 14、大面板 20、全屏浮层 24。

## 5. 动效语言

原则：**动效解释变化，不制造热闹。** 只有三种东西会持续运动：告警信号、实时数据刷新、氛围光。

### 5.1 时长与曲线

| 令牌 | 时长 | 用途 |
| --- | --- | --- |
| `--vi-dur-instant` | 90ms | 按压、勾选 |
| `--vi-dur-quick` | 160ms | 悬停、切换 |
| `--vi-dur-base` | 260ms | 展开、浮层 |
| `--vi-dur-slow` | 480ms | 入场、路由 |
| `--vi-dur-epic` | 900ms | 仪表指针、首屏主视觉 |

| 曲线 | 值 | 性格 |
| --- | --- | --- |
| `--vi-ease-ink` | `cubic-bezier(.2,.8,.2,1)` | 墨入水：快起慢收，默认 |
| `--vi-ease-brass` | `cubic-bezier(.34,1.4,.64,1)` | 铜簧：轻微回弹，用于指针、开关 |
| `--vi-ease-tide` | `cubic-bezier(.65,0,.35,1)` | 潮汐：对称，用于循环 |

### 5.2 标准动效

| 名称 | 描述 |
| --- | --- |
| 墨晕入场 `vi-bloom` | 透明度 0→1、模糊 8px→0、上移 10px，480ms；列表子项错开 40ms，最多 8 项 |
| 路由转场 | 旧页淡出 120ms，新页墨晕入场；保持滚动复位 |
| 数字滚动 | 数值变化时逐位滚动，600ms，等宽数字防抖 |
| 指针归位 | 仪表指针用铜簧曲线越过 4% 后回落，900ms |
| 信号呼吸 | 仅「警」：外环 2.4s 呼吸，内核常亮 |
| 刷新扫光 | 数据刷新时卡片顶边扫过一道 1px 光，600ms |
| 聚光 | 见 4 |

`prefers-reduced-motion: reduce` 时：入场改为纯淡入 120ms，循环动画全部停止，指针直接到位。

## 7. 信号灯系统

信号灯是全站最重要的语义组件，统一为一套 `<Signal>`。

**构造**：内核（实心形状）+ 光晕（同色 30% 透明，半径 ×2）+ 刻度环（发丝线，仅 L 尺寸）+ 文字。

| 尺寸 | 直径 | 场景 |
| --- | --- | --- |
| S | 8 | 列表行、标签内 |
| M | 14 | 卡片角标、表格 |
| L | 40 | 信号灯面板、看板主信号 |
| XL「天灯」 | 120 | 信号灯模块主视觉：同心三环 = 短 / 中 / 长期，三环各自着色 |

行为：状态改变时先熄灭 120ms 再以新颜色点亮（让人注意到变化）；「警」持续呼吸；悬停显示判定依据与数据时间。

## 8. 仪表盘

### 8.1 KPI 单元

自上而下：眉题（指标名 + 期别，caption）→ 主数值（figure-xl，单位降级）→ 变化（箭头 + 数值 + 「较上期」，语义色）→ 迷你走势（48px 高，末点放大并标值）→ 来源与日期（caption，次文字）。左上角挂 S 号信号灯。

### 8.2 浑仪仪表 `<Armillary>`

270° 弧，外环刻度（主刻度 + 次刻度），内环为区间色带（稳 / 观 / 警），指针为铜色细针 + 圆心铆钉；中心显示数值。用于 PMI、失业率等有阈值的指标。

### 8.3 版式模板

| 模板 | 结构 | 用于 |
| --- | --- | --- |
| 主视觉 Hero | 左 7 列标题 + 一句结论；右 5 列天灯或浑仪 | 每个看板首屏 |
| 读数带 Strip | 一行 4–6 个 KPI，手机横滑 | 宏观快照 |
| 墙面 Wall | 12 列自由编排，用户可拖拽、增删 | 个人工作台 |

## 10. 专属阅读器

长文（研究报告、政策与法规语料、史鉴卷、学者专栏）统一进入阅读器 `<Reader>`。

| 项 | 规范 |
| --- | --- |
| 版心 | 每行 32–38 个汉字（约 `36em`），桌面居中；左侧目录 240px，右侧批注栏 280px（可收起） |
| 正文 | `--vi-fs-read`，Read 字族，行高 1.9，段间距 1em，首行不缩进 |
| 标题 | h1 Display 34/1.2；h2 24；h3 19；章节号用铜色 |
| 引文 | 左侧 2px 铜线 + 次文字色，字号降一级 |
| 脚注 | 正文中上标，悬停 / 点按弹出卡片，文末汇总 |
| 阅读主题 | 夜（玄漆）/ 宣纸 / 护眼（`#F3EAD3` 底、`#3A3226` 字） |
| 字号 | 4 档：小 16 / 标准 18 / 大 20 / 特大 22，记忆到本地 |
| 进度 | 顶部 2px 进度线 + 目录高亮当前章节 + 「约剩 N 分钟」 |
| 专注模式 | 隐藏导航与批注栏，非当前段落降低到 55% 不透明 |
| 批注 | 选中文本 → 划线（朱 / 铜 / 青三色）+ 笔记，存入个人工作台 |
| 手机 | 单栏全宽，边距 20；目录与批注改为底部抽屉；点按屏幕中部切换沉浸 |

## 11. 落地顺序

1. 令牌与全局材质（本规范 §1–§5）：新文件 `styles/vi2/*.css`，通过映射旧变量让存量 221 个模块整体换肤。
2. 样张页 `/#/design`：本规范的活体版本，CI 截图验收。
3. 组件：`<Signal>`、`<Armillary>`、`<Kpi>`、`<Spotlight>`、`<Reader>`。
4. Shell 2.0：命令面板、个人首页、底部 Dock（手机）、右侧上下文面板。
5. 核心视图按 §7–§9 重做：中枢看板、信号灯、神州活图。
6. 存量模块的硬编码颜色（`#22d3ee` 等）用 codemod 迁移到令牌。

## 12. 验收清单
