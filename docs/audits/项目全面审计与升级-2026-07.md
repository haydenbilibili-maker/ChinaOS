# ChinaOS 项目全面审计与升级（2026-07）

> 审计日期：2026-07-23  
> 范围：工程健康、信息架构、UI/UX、数据与内容、性能、安全与可靠性、文档  
> 边界：本轮不是正式渗透测试；未修改官方统计数字，未 commit / push / deploy；未触碰两个归属未定文件。

## 1. 执行摘要

审计基线可构建、现有 107 项测试全绿，史鉴·中华原有 58 卷检查全绿；未发现 P0 级阻断性运行时或数据错误。多轮叠加的主要风险集中在 P1：注册表交叉链接发生 10 处路径漂移，UI 检查存在“报告失败但退出码仍为 0”的假绿，世界线 33 卷未进入史鉴门禁，且全局搜索索引被首屏空闲预热拉入主包。

本轮已修复上述问题，并新增只读、幂等的项目完整性门禁。生产构建主入口从基线 **1,999.38 kB / gzip 551.82 kB** 降至 **395.87 kB / gzip 134.96 kB**；Lucide 公共块仍为 **698.36 kB / gzip 123.32 kB**，ECharts 公共块仍为 **1,045.06 kB / gzip 347.70 kB**，二者已列为下一轮按真实加载瀑布优化的对象。

## 2. 风险分布

- **P0：0 项**。未发现阻断构建、主路由空白、史鉴卷缺 body、未来日期或官方数字被误改。
- **P1：5 项，已修复 5 项**。交叉链接漂移、通用门禁缺失、UI 门禁假绿、世界线漏检、搜索索引污染首屏。
- **P2：4 项，已修复 1 项，待办 3 项**。README 状态漂移已修；Lucide/ECharts 大公共块、生成脚本缺少统一 `--check`、大量静态可信 HTML 注入缺乏来源契约仍待后续。

## 3. 发现与处置

### P1-01 · 交叉链接路径漂移（已修复）

**证据**：新增门禁首次运行发现 10 处未注册路由，集中在 `/financeRmb`、`/greenfinance`、`/tech`、`/finance`；实际 registry 路径分别为 `/rmb`、`/green-finance`、`/tech-policy`、`/finance-system`。  
**影响**：从离岸、金融、生态、一带一路、新质生产力、基础研究、住房、教科人才、资本市场等模块点击会被通配路由重定向至中枢看板，形成“看似可点、实际丢失上下文”的软死链。  
**处置**：修正 `app/src/modules/shared/moduleCrossLinks.js` 10 处目标；`check:integrity` 现为 0 failure。

### P1-02 · 缺少 registry/路由通用门禁（已修复）

**证据**：原根脚本仅有 `check:ui` 与 `check:shijian`，无法检查 279 个模块的 id/path/group/import、图标白名单、史鉴静态卷与路由一一对应、交叉链接或全局基准日。  
**处置**：新增 `scripts/check-project-integrity.mjs` 与 `npm run check:integrity`，覆盖：

- GROUP/MODULE id 与 path 唯一性；
- group/subgroup 合法性；
- 279 个 lazy import 文件存在性；
- 注册图标是否进入显式白名单；
- 58 个 SJ 与 33 个 SJW 静态卷和路由双向一致；
- 168 组模块交叉链接的目标路由；
- `AS_OF_BASELINE` 合法、非未来，超过 45 天告警。

根脚本新增 `npm run check`，串联完整性、UI、史鉴双线与 Vitest。

### P1-03 · UI 门禁假绿（已修复）

**证据**：基线 `npm run check:ui` 报告三项 failure（santi、shijian、shijian-world），但进程退出码为 0；其中三体使用合规 `SelectorBar`，史鉴两线委托给 `ShijianHtmlShell`，属于检查器误判。  
**处置**：检查器识别 `SelectorBar` 与 `ShijianHtmlShell` 委托契约，并在真实失败时设置非零退出码。现状：199/199 Page 全通过。

### P1-04 · 史鉴·世界未进入门禁（已修复）

**证据**：原 `verify-sj-html.mjs` 只扫描 `app/public/shijian/`，而世界线文档仍把 `check:shijian` 描述为“中华线 0 回归”。  
**处置**：门禁扩展至 58 SJ + 33 SJW，统一检查 body/header/footer、签名 SVG、reduced-motion、外部脚本/样式依赖、网络请求、浏览器存储；保留中华案例几何与 NODE_DATA 专项规则。世界线路线图同步更新。

### P1-05 · 搜索索引进入首屏（已修复）

**证据**：基线构建主入口 `1,999.38 kB / gzip 551.82 kB`。`Shell.jsx` 静态导入并在空闲期预构建 `buildSearchIndex`，使大量人才/词典 Seed 的索引代码进入初始依赖图；全局搜索即使从未打开也承担下载与解析成本。  
**处置**：

- `GlobalSearch` 改为仅打开时 lazy mount；
- 移除 Shell 空闲预热，由搜索面板自身展示“正在建立索引”；
- `AiLauncher` 拆为 lazy chunk；
- 注册表图标改为 `moduleIcons.js` 显式白名单，避免 Shell 动态命名空间查找。

**结果**：主入口降至 `395.87 kB / gzip 134.96 kB`，gzip 减少约 **75.5%**。搜索功能首次打开会承担一次可见的索引构建，这是用非关键交互延迟换首屏稳定性的明确取舍。

### P2-01 · README 与实际 IA 漂移（已修复）

**证据**：根 README 仍写“13 个分组、100+ 模块”，`app/README.md` 仍按四层早期地基描述并把默认端口写成 5180；实际为 19 分组、279 注册模块、277 可见入口，含史鉴双线、三体 R4、经济大盘八 Tab。  
**处置**：更新根 README、app README、验证入口与史鉴世界质量门描述。

### P2-02 · Lucide / ECharts 公共块仍大（待办）

**证据**：最终构建 `lucide-react` 为 698.36 kB（gzip 123.32 kB），`EChart` 为 1,045.06 kB（gzip 347.70 kB）。多个 lazy 模块仍使用 `import * as Lucide`，会扩大公共图标块。  
**建议**：下一轮先用浏览器 Network/coverage 确认首屏实际请求，再机械替换剩余 namespace import；ECharts 按图型评估 `echarts/core` + 按需组件，不在无瀑布证据时贸然全库重写。

### P2-03 · 生成脚本缺少统一 check/dry-run（待办）

**证据**：史鉴再生脚本多数直接 `writeFileSync`，`patch-sj-slices.mjs` 虽有完整性断言但无 `--check`；直接验证幂等性会污染工作区。  
**建议**：为核心再生器增加内存生成 + 内容比较的 `--check` 模式，再纳入 CI；本轮未为“证明幂等”直接重写 40+ 卷。

### P2-04 · HTML 注入与 iframe 边界需要持续约束（待办 / 本轮不建议大改）

**证据**：多个迁移型模块通过 `dangerouslySetInnerHTML` 注入仓库内静态母本；史鉴 iframe 为同源可信单页，未加 sandbox，以支持现有深链与 postMessage 协议。  
**判断**：当前未发现用户输入直接进入这些注入点，也未发现 SJ/SJW 外部脚本、网络请求或浏览器存储；风险是“未来数据源变为远端/用户可控”时的契约退化。  
**建议**：为静态 HTML 数据层补“仅构建期可信常量”注释与测试。史鉴 sandbox 若要启用，需先设计同源 postMessage 与独立打开兼容方案；本轮不做可能破坏功能的象征性加固。

## 4. 分域审计结论

### 工程健康

生产 build 与 15 个测试文件、107 项测试通过。根脚本现有统一 `check`。未配置 ESLint/TypeScript 全量类型检查，本轮不为扩大工具链而引入新依赖；现有 stylelint 只覆盖 CSS。

### 信息架构

registry 为 19 分组、279 模块、277 可见入口；史鉴·中华 58 路由与世界 33 路由均与静态卷一一对应。经济大盘的半年解读、促消费保持 `navHidden` 深链别名，避免侧栏重复入口。交叉链接 10 处漂移已清零。

### UI/UX 与可达性

UI 契约 199/199；史鉴双线全部具 `prefers-reduced-motion`，React 壳具有移动抽屉、键盘搜索、面包屑、主题/密度控制和 iframe 失败态。浏览器自动化服务在本次会话无法创建标签，因此未宣称完成视觉回归；最终仍建议人工抽检 dashboard、经济大盘移动断点、SJ/SJW iframe 及搜索首次打开。

### 数据与内容

全局 `AS_OF_BASELINE=2026-07-14`，经济数据快照 `2026-07-15`，相对审计日分别为 9 天与 8 天；未触发 45 天陈旧门槛。促消费政策与 H1 读数单独标注 2026-07-13/15，世行 Tab 对缺序列使用〔存疑〕。本轮未改任何官方数字。

### 性能

搜索索引由首屏预热改为首次打开按需加载；模块仍保持 registry lazy chunk。大块剩余项见 P2-02。`app/dist` 总体约 36 MB，其中大量专题页与静态语料按路由分发，不能用总体体积直接等同首屏负载。

### 安全与可靠性（非正式安全审计）

开发 HLS 代理有 host allowlist、私网地址阻断与协议/扩展名校验。SJ/SJW 门禁确认无外部脚本/样式、fetch/XHR、浏览器存储。发现的 `dangerouslySetInnerHTML` 目前承接仓库内静态内容，不据此夸大为可利用 XSS；应继续防止远端或用户输入穿透。
