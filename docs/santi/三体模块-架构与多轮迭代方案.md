## 1. 定位一句话与模块边界

### 1.1 定位

**三体模块**：以刘慈欣科幻作品中的**典故与理论设定**为素材库，抽取可迁移的**机制抽象**，映射到文明博弈、国家竞争、社会治理与人的自我探索——作为 ChinaOS 的**思想实验透镜**，而非文学评论站或同人站。

### 1.2 边界（必须写清）

| 本模块是 | 本模块不是 |
|----------|------------|
| 文明 / 治理 / 博弈的**机制透镜** | 史鉴 SJ（史料·五力·治乱相位） |
| 概念提纯 → 现实对照的**台账产品** | 纯科幻同人、剧情百科、二创叙事 |
| 与威慑战略 / 博弈论 / 台海等的**交叉入口** | 对现实政治的阴谋论推演或断言 |
| 冷峻中立的「相似机制 + 关键差异」双栏 | 用小说情节直接「证明」现实结论 |

**与深度调研系列的对齐**：术语优先、冷峻中立、穿透叙事看机制；UI 可走深空差异化令牌，但交互范式仍服从 ChinaOS 模块惯例（IntroCard / 选择器 / 台账 / 交叉链）。

**新闻稿级一句话（Press Release 前测）**：

> 若你在读台海、威慑、权力逻辑或治国沙盒时感到「缺一张把极端思想实验压成可对照台账的透镜」——三体模块把黑暗森林、执剑人、思想钢印等概念拆成可 drill-down 的机制卡片，每张强制写出「像什么」与「为什么不能直接搬」。

## 2. 典故 / 理论库草案（规划层 · 母本 seed）

> **硬约束（对齐史鉴「母本先行」精神）**：Round 1 落盘任何理论卡片前，该条目须在本表有 seed。不确定标〔存疑〕。  
> **映射维编码**：`C` 文明博弈 · `N` 国家竞争 · `G` 社会治理 · `S` 自我探索（可多选）。  
> **关键差异栏**：交付时每条映射必须双栏齐全；本表只预埋「差异意识」提示，正文阶段展开。

### 2.1 《三体》三部曲（核心）

## 3. 信息架构（IA）

### 3.1 建议五分法（可裁为四分）

| 柱 | 代号 | 职责 | Round |
|----|------|------|-------|
| **总论索引** | ST-00 | 定位、方法论、卷目导航、与 ChinaOS 交叉入口 | R1 |
| **理论光谱** | Spectrum | 概念卡网格 + 筛选（作品/映射维/成熟度） | R1 |
| **文明博弈** | Civ | 黑暗森林坐标系、公理→策略链、跨文明对照台账 | R2 |

**推荐方案 A（系列化，对齐史鉴）** — 待裁定

```
  santiCiv   /modules/santi/civ      group:santi  subgroup:civ      // R2
  ...
```

**备选方案 B（轻量挂靠）** — MVP 最快  

```
group: 'cognition'   // 与博弈理论、威慑战略、修昔底德同层
id: 'santi', path: '/santi'
// 单页多 Tab，R2 再拆路由
```

**备选方案 C**：`group: 'lens'`（与深度透视、文明透视并列）——强调「内容透镜」而非「认知内核」。

| 方案 | 优点 | 代价 |
|------|------|------|
| A 独立 group | 多卷可扩展、侧栏清晰、品牌独立 | 改 GROUPS、导航权重上升 |
| B cognition | 与博弈/威慑心智邻近、改动小 | 系列膨胀后侧栏拥挤 |
| C lens | 与文明透视并列 | 易被理解成「又一篇深度报告」 |

**副题命名约定（对齐 registry）**：主名优先 4 字；副题三段式。草案：

- 三体总论 · `文明透镜 · 机制映射 · 思想实验`
- 理论光谱 · `公理设定 · 概念卡片 · 双栏对照`
- 文明博弈 · `黑暗森林 · 猜疑链条 · 技术爆炸`
- 国家社会 · `威慑动员 · 锁死代际 · 规则战争`
- 自我探索 · `执剑伦理 · 认知钢印 · 阶梯抉择`

### 3.3 实现形态（技术方向 · 非本轮实现）

- **优先**：React 模块（`app/src/modules/santi/`），复用 `ModuleParadigm`、交叉链接 `moduleCrossLinks`。  
- **不采用**：史鉴式单文件自足 HTML iframe（SJ 铁律不适用）；除非未来做「可独立传播的长文卷」再议。  
- **数据**：概念库 JSON/JS 内存模块（如 `santiCanon.js`），禁止浏览器存储。

## 4. 核心方法论（自有框架 · 勿与「五力」撞名）

### 4.1 名称提案（待裁定其一）

| 候选名 | 定义一句 |
|--------|----------|
| **三体透镜·四步映射法**（推荐） | 概念提纯 → 机制抽象 → 现实对照（相似+差异）→ 台账判定 |
| 宇宙社会学透镜 | 易被误认为只覆盖「公理/黑暗森林」一条线 |
| 深空博弈坐标系 | 偏视觉，方法论感弱 |

**刻意交叉引用、但不合并命名**：史鉴「五力衰变」、史鉴「四步法」——三体侧用「四步**映射**」区分「四步**史鉴引擎**」。

### 4.2 四步映射法（冻结候选）

1. **概念提纯（Extract）**  
   去掉情节与人物，留下可陈述的机制命题（一句话 + 前提条件）。
2. **机制抽象（Abstract）**  
   标明主体、信息结构、成本函数、均衡形态（可用简单博弈树/因果链，不作伪数学炫耀）。
3. **现实对照（Mirror）** — **强制双栏**  
   - 相似机制：现实中何种结构产生相近激励  
   - 关键差异：尺度、制度、技术、伦理、可逆性上的不可平移点  
4. **台账判定（Ledger）**  
   对「该透镜是否提升了我们对某类问题的解释力」做显式判定：  
   **已兑现**（解释力被其他模块/公开事实支撑）· **未决** · **已证伪/慎用**（过度外推已被指出）。

### 4.3 四维映射轴（内容坐标，非动力学「力」）

| 轴 | 问的问题 | 典型概念 |
|----|----------|----------|
| 文明博弈 C | 生存竞争与接触策略如何稳态？ | 黑暗森林、技术爆炸、降维 |
| 国家竞争 N | 代差、威慑、封锁如何改写均衡？ | 智子、水滴、面壁、制裁隐喻 |
| 社会治理 G | 动员、认知、代际如何维持秩序？ | 思想钢印、流浪/逃逸、儿童政权 |
| 自我探索 S | 个体在极端结构中如何选择？ | 执剑人、阶梯、领航员 |

### 4.4 单卡字段契约（理论光谱）

```
id / title / work / oneLiner
preconditions[]          # 思想实验前提
dims: [C|N|G|S]
similarMechanisms[]      # 相似机制（可链到 ChinaOS 模块）
criticalDiffs[]          # 关键差异（必填，禁止空）
ledger: { realized, open, caution }  # 三列台账摘要
sourcesNote              # 出处作品+章节级定位（不整段摘抄）
uncertainty: boolean     # 〔存疑〕
crossLinks: moduleId[]
```

## 5. 单页 / 多卷结构与 MVP 取舍

### 5.1 决策

| 选项 | 结论 |
|------|------|
| 首期一整本百科 | ❌ 内容债与版权风险高 |
| **Round 1：一卷总论 + 光谱 MVP** | ✅ 推荐 |
| Round 2+ 按柱拆路由分册 | ✅ 与方案 A 对齐 |

**MVP 成功标准（产品）**：

1. 用户 3 分钟内理解「这不是同人站」；  
2. 至少 12 张概念卡具备完整双栏；  
3. 至少 5 条到既有模块的可点击交叉链（威慑、博弈、台海、权力逻辑、沙盒等）；  
4. 零大段原文；每条敏感映射有差异栏。

### 5.2 为何不首期多卷并行

- 机制框架未在用户侧验证前，分卷会导致重复解释与口径漂移。  
- 光谱卡是可复用原子；Civ/State/Self 是编排层——先原子后编排（同史鉴「母本先行」）。

## 7. 交互范式

| 范式 | 说明 |
|------|------|
| **理论卡片 drill-down** | 网格 → 侧栏/抽屉展开四步与台账 |
| **映射双栏** | UI 上相似/差异并置，缺一不可提交（内容门） |
| **台账三列** | 已兑现 / 未决 / 慎用（对应 4.2 Ledger） |
| **图谱关系** | 概念间「导出/前提/对抗」边（R2；R1 可用静态邻接表） |
| **交叉链** | 卡片脚注链到 registry 模块（`moduleCrossLinks` 扩展） |
| **筛选** | 作品 × 映射维 × 台账状态 |

## 8. 内容红线

1. **版权**：只允许极短必要引用（设定名、公理表述级）；禁止大段原文、禁止整章复述式剧透文。情节只用「机制所需最小上下文」。  
2. **禁止政治阴谋论臆造**：不得用小说情节「坐实」现实未公开权力斗争；映射停在机制与公开可讨论的结构层。  
3. **裸类比禁令**：无「关键差异」栏的映射视为不合格内容，不得上线。  
4. **存疑标注**：作品归属、学界/读者常见误读、与现实理论（如国际关系现实主义）的关系不清时标〔存疑〕。  
5. **敏感动员类（ST-23 等）**：强制成本栏 + 差异栏 + 交叉「权力逻辑/沙盒」；禁止口号化。  
6. **儿童政权等**：避免煽情与年龄歧视表述；聚焦制度缓冲缺失这一机制。  
7. **并行施工**：本迭代不修改 `econdash` / `econH1Review` / `econConsume*`。
