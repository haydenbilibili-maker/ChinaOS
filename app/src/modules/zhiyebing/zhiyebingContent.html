注记 · 分析立场 本片以劳动权益与职业健康视角分析,把职业病理解为可预防、应被保障的劳动损害,尊重患者、不渲染、不猎奇,聚焦制度(认定、保障、防治)而非个体遭遇。本片不把这个人群当作命运的承受者,而是作为工业化身体代价的承载者来分析——他们的肺替整个工业化吸收了不计价的磨损。涉及具体认定与赔偿措施的评价存在分歧处,以归因形式呈现;本片是常规判词片,会就「代价该由谁承担」给出明确方向。
模块隐喻是延迟显现的硬件损耗(Deferred Hardware Damage):职业病/工伤群体是 China OS 一批运行多年、累积吸收物理损伤却延迟显现的硬件——身体在粉尘 / 毒物 / 高强度环境中持续受损,损耗条悄悄累积;而损伤以长潜伏期(尘肺)在离岗多年后才暴露,等病来了,人早已离开矿井、工地,甚至那家企业都没了。这份损耗从未被记入「运行时成本」(职业健康代价不计入劳动报酬);索赔时还要证明「损伤来自哪台主机」(劳动关系举证),而农民工常无合同——「确诊容易、认定难、赔偿更难」就是这个群体的写照。本片以劳动权益视角主张:工业化的身体代价,该从个人的肺拉回到预防、认定与保障的制度责任上。

C2 · 延迟显现:磨损的长潜伏期

本片独特机制 · 离岗多年后才显现

注记(分析立场):本节呈现本片的独特机制——职业病损伤的延迟显现。这不是为了渲染,而是因为「延迟」正是认定难、保障难的根源;理解它,才能理解这个群体的处境。

本片的独特机制在于——职业病(尤其尘肺)的损伤有长潜伏期,常在离岗多年后才显现。这种「延迟显现」使因果链断裂:发病时人已离开致病岗位(甚至企业已不存在),损伤被从「劳动现场」剥离,成为「个人的病」——而这正是认定难、保障难的根源。损伤在劳动时未被计入报酬或成本,身体的磨损是隐性的、被透支的(↔ GY-23 健康透支 / GY-27 货车司机职业健康):防护成本被省下,代价延迟到个人身上。运行的时候不计价,账单延迟几十年才到,这是职业健康最隐蔽的不公。

延迟显现的进程链:运行 → 损耗累积 → 离岗 → 发病

运行受损身体在粉尘/毒物/高强度环境中持续受损——损耗在运行(在岗)时悄悄累积,却不可见、不计价。
长潜伏期尘肺等职业病的损伤累积多年后才发病——离岗多年后才显现(本片独特机制)。
因果断裂发病时已离岗/企业已不存在 → 损伤与劳动现场脱钩 → 被当作「个人的病」——延迟显现使责任难追溯(↗ C3)。

C3 · 认定难:证明损伤来自哪台主机

举证难 · 三重门 · 与 GY-05 同构

注记(分析立场):本节分析的是「确诊容易、认定难、赔偿更难」这一结构性障碍。与法律黑洞(↗ GY-05)同构——本片不渲染极端个案,只呈现「举证难使损伤难以追溯到责任主体」的机制。

职业病/工伤认定的核心障碍是「举证难」——需证明劳动关系(而农民工常无合同 ↗ GY-05 L4)、需证明职业接触史、诊断周期长、用人单位可能已不存在或不配合。「确诊容易、认定难、赔偿更难」是这个群体维权的写照,是 GY-05(法律黑洞)在职业健康端的体现。损伤是真的,但要证明「损伤来自哪台主机」,却成了几乎不可能完成的事——延迟显现(C2)更让这件事雪上加霜:等病发了,企业可能早注销了。

确诊—认定—赔偿的三重门

医学确诊确诊一个尘肺也许不难——医学上的诊断是第一步(620 诊断机构在建)。
法律认定难的是法律上认定它是职业病——需证明劳动关系 + 职业接触史,诊断周期长、取证难(↗ GY-05 L4)。
工伤赔偿再难的是拿到赔偿——工伤赔偿/职业病待遇;用人单位可能已注销/不配合/无力赔付,责任主体消失。
三道门医学确诊 → 法律认定 → 工伤赔偿——每一道门都可能把人卡在门外;维权漫长(开胸验肺式的极端个案是其象征)。

举证难的几条:证明损伤来自哪台主机

举证难认定职业病需证明劳动关系(无合同的农民工举证难 ↗ GY-05 L4)+ 职业接触史——「证明损伤来自哪台主机」。
诊断周期长诊断周期过长、职业史/接触史取证难——确诊与认定之间的鸿沟。
用人单位缺位企业已注销/不配合/无力赔付——责任主体消失;延迟显现(C2)加剧了这一点。
制度改进简化诊断、放宽举证(部分情形举证责任转移)、农民工尘肺病防治意见——政策在降低认定门槛,但举证难仍是结构性障碍。

C4 · 因病致贫致债:损伤的下游

塌方下行链 · 职业病→极贫→债务

注记(分析立场):本节以劳动权益取向分析职业病的下游后果。核心是一条「治疗费 + 断收入 + 无赔偿」叠加的塌方下行链——本片不渲染个体困苦,只呈现「职业病推向贫困与债务」的机制。

职业病的下游是因病致贫致债——治疗费用高(尘肺需长期治疗)、丧失劳动能力(断收入)、认定赔偿难(无补偿)三者叠加,使职业病家庭陷入贫困与债务(↗ GY-43 极贫 / GY-32 债务),是 GY-06 M5(农民工老去)→ GY-43(极贫)→ GY-32(债务)的一条完整下行链。一个尘肺病人的人生下游,往往是一条清晰的下滑线:治病要花钱,病了不能干活没了收入,又因为认定难拿不到赔偿——三样叠在一起,就是因病致贫、借债度日。职业病不只是一个肺的病,是一个家庭的塌方。

塌方下行链:职业病 → 极贫 → 债务

治疗负担尘肺等需长期治疗、洗肺、并发症——医疗费用高(↗ GY-15 医保的覆盖缺口)。
断收入发病后无法继续从事体力劳动——收入断绝(↗ GY-06 M5)。
无补偿认定赔偿难(C3)——拿不到工伤赔偿/职业病待遇,无补偿兜底。
