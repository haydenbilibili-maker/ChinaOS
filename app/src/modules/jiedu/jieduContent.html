J2 · 疾病模型 vs 道德模型:两种框架的张力

本片核心张力 · 怎么理解复发是分野

注记(分析立场):本节呈现两种看待成瘾的框架。本片站在疾病模型(公共卫生取向)一侧,但如实呈现道德模型的逻辑,因为它是污名与歧视的来源;理解它,才能理解康复者的处境。

本片的核心张力在于——成瘾在两种框架间被拉扯:疾病模型(成瘾是慢性、复发性的脑部健康问题,应治疗与减害)与道德/犯罪模型(吸毒是道德污点与违法行为,应惩戒与管控)。中国的戒毒制度兼有医疗(戒治)与管控(强制隔离)双重属性,反映了两种框架的并存。怎么理解「复发」,是两种模型最尖锐的分野:是治疗中的正常波折,还是「不思悔改」的证据?

两种框架的并置

框架一 · 疾病模型(本片取向)
慢性脑病 / 治疗 / 减害

成瘾是慢性复发性脑疾病——应以治疗、康复、减害(如美沙酮维持治疗)对待;复发是疾病特性而非意志薄弱。

⇌
框架二 · 道德/犯罪模型
道德污点 / 惩戒 / 记录

吸毒是道德污点 + 违法行为——应以惩戒、管控、记录对待;污名与歧视由此而来。

制度的双重属性与复发的理解

疾病模型成瘾是慢性复发性脑疾病,应以治疗、康复、减害对待;复发是疾病特性而非意志薄弱——公共卫生取向的基础认知。
道德模型吸毒是道德污点与违法行为,应以惩戒、管控、记录对待——污名与歧视的来源(↗ J3)。
制度双重属性中国戒毒体系兼有医疗戒治与强制管控——社区戒毒(社区)、强制隔离戒毒(强制)、社区康复(回归),反映两种框架并存(《禁毒法》)。
复发的归因复吸率高低、复发的归因(疾病特性 vs 意志/环境)——疾病模型下复发是治疗课题,道德模型下复发是「不思悔改」;如何理解复发,决定如何对待康复者。
怎么理解「复发」,是两种模型最尖锐的分野是治疗中的正常波折,还是不思悔改的证据?

这个人群被夹在两种看待成瘾的方式之间。疾病模型说:成瘾是一种会复发的慢性脑病,该治疗、该减害、该有耐心。道德模型说:吸毒是污点和违法,该惩戒、该记录、该警惕。中国的戒毒制度两种属性都有——既戒治也管控。怎么理解「复发」,是两种模型最尖锐的分野:是治疗中的正常波折,还是「不思悔改」的证据?而一个康复者被怎样对待,取决于社会用哪种模型看他。(↗ J1 康复事实 / ↗ J3 残留标记 / ↗ J4 复发防控)

涉毒记录 · 权限残留 · 与 GY-44/32 同构

注记(分析立场):本节分析的是「戒断 ≠ 标记清除」这一结构性后果。与社区矫正(↗ GY-44)、失信(↗ GY-32)同构——本片不渲染个体遭遇,只呈现「持久标记触发连锁歧视」的机制。

J4 · 回归社会:就业、家庭、复发防控

接住比标记更能降低复发 · 与 GY-44 同理

注记(分析立场):本节以公共卫生取向分析回归课题。核心主张是「接住康复者比标记康复者更能降低复发」——这与 GY-44 安置帮教同理,本片明确给出这个方向。

戒毒康复人员的回归面临三重课题——就业难(涉毒标记 + 技能/社会脱节)、家庭关系修复、复发防控(环境、心理、社会支持)。「无缝衔接」的安置帮扶、社区康复、就业支持不足时,回归断点累积可能推向复发;社会支持与去污名是降低复发、实现真正康复的核心(与 GY-44 安置帮教同理)。让一个人真正戒断,靠的不只是戒治所里的隔离,是出来之后能不能被接住。

回归的三重课题

就业断点涉毒标记歧视 + 戒治期间的社会/技能脱节——就业是回归的第一难关(↔ GY-44 J3)。
家庭修复成瘾对家庭关系的破坏、家庭支持对康复的关键作用——家庭是康复的重要支持。
复发防控环境(旧交往圈)、心理、社会支持——复发是回归的最大风险;社区康复、心理干预、社会支持降低复发。
社会支持核心去污名 + 就业接纳 + 社区康复——「接住」康复者比「标记」康复者更能降低复发(↔ GY-44 J4/J5:过度标记反推再犯/复发)。
减害理念美沙酮维持治疗、清洁针具等减害措施(针对特定毒品/防 HIV ↗ GY-57)——公共卫生取向的干预。
降低复发最有效的,不是更紧的管控,是更实的支持

让一个人真正戒断,靠的不只是戒治所里的隔离,是出来之后能不能被接住——有没有工作、有没有家、有没有一个不把他当污点的社区。回归的断点越多,复发的风险越大。这和社区矫正(↗ GY-44)是同一个道理:过度的标记和歧视,反而把康复者推回旧路。

合成总判词 · 承认康复 · 淡化标记 · 接住回归 戒毒与社区康复人员是 China OS 一个被标记「需修复」、且修复成功率其实很高的进程——戒断者 428 万远多于在册 75 万,多数人能康复回归。但成功修复的进程仍带着一枚「涉毒记录」的持久标记,在就业、出行、被信任的每一刻触发歧视,使康复者的回归遭遇与刑释人员(↗ GY-44)、失信者(↗ GY-32)相同的「权限残留」。

这个人群被夹在疾病模型(成瘾可治、复发是病程、该减害与接纳)与道德模型(吸毒是污点、复发是不悔改、该惩戒与警惕)之间——而一个康复者被怎样对待,取决于社会选哪种模型。本片以公共卫生视角主张一个朴素的方向:既然系统已经承认了 428 万人的康复,就该让他们的标记也能翻篇——因为降低复发最有效的,不是更紧的管控,是更实的支持和更少的歧视。

承认康复、淡化标记、接住回归,这是把「戒断之后」变成「真正康复」的唯一路径。
