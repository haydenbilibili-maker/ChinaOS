执法在前，编制在外
模块隐喻是借权代理进程(Privilege-Borrowing Proxy):这个人群是 China OS 内核(体制/编制)与用户空间(社会)之间的代理进程——它持一枚「临时授权令牌」执行国家权力(巡查、调解、执法辅助、信息采集),却没有永久账户(无编制);所有从社会向上抛出的「异常」(矛盾、冲突、投诉)由它第一个 catch,而它本身随时可被 kill(清退、切割)、且出事先背锅。签名图:内核区「体制 · 编制(持久账户)」与用户空间「社会」之间,一层代理进程「网格员/辅警/社工/协管 · 数百万」,持「borrowed sudo · 临时授权」令牌向下执行;向上的异常流(矛盾/冲突/投诉)全部先打到这一层;进程标签「non-persistent · killable · 同工不同酬 · 无编制」;底注「权力的临时工化 · 问责缓冲器 · 上面千条线,下面一根针」。这是 GY-05「管理外包化」在治理领域的同构版:平台用外包骑手保护正式员工,体制用编外治理者保护编制权威。

M1 · 看不见的数百万

规模与构成

网格员、辅警、社区工作者、城管协管、各类协管员构成数百万乃至千万级的「编外治理大军」——规模不透明却无处不在;他们是国家权力触达社会末梢的实际执行者,也是统计上最模糊的人群之一。国家权力的最后一公里,是由一群没有编制的人执行的。

注记(口径处理):编外用工的规模本身就是个黑箱,本片所列量级为训练知识基线 + 公开报道与政策口径的估算,标「约」者待权威年度数据回填,不等同精确统计;不对任何个体作评判,讨论的是编外治理者作为人群的结构位置。

构成谱系:四类编外治理者

公安辅助 辅警

公安辅助力量,全国数百万量级——执法辅助、巡逻、协勤,却不具备完整执法主体资格(↗ M2 借权的尴尬)。

基层信息 网格员

基层信息采集与巡查的毛细血管,数百万量级——同时对接十几个条线,是「一根针」的针尖(↗ M4)。

党建治理服务 社区工作者

党建/治理/服务一肩挑,数百万量级——女性占比高(↗ GY-17 再就业的下沉出口),2024 意见正推动其职业化。

综合执法 城管 / 交通 / 市场协管

城管、交通、市场、安全、综治、调解员、防疫临时招募——规模庞大且高度临时化,「多员合一」改革正在整编这些队伍。

招考火爆的悖论 · 黑箱人群的不可见

规模黑箱辅警/网格员/社工/协管合计数百万至千万级,但缺乏透明统计——编外用工的规模本身就是一个黑箱,这正是这个人群「不可见」的第一层来源。
招考报录比网格员/社工招考报录比奇高(报名 6000+ 录 74,约 1:84),月薪约 3700 元——待遇不高却挤破头。
下沉投影连「类体制」的编外岗都成了香饽饽——是县域/基层就业稀薄(↗ GY-20)与编制崇拜(↗ GY-07)的下沉投影。
性别化社区工作者、网格员中女性占比高——基层治理的末梢劳动高度性别化(↗ GY-17 中年女性再就业的下沉出口之一)。
系统运转的默认背景你只在被他们管理、或他们出事时,才想起他们存在

这个人群的不可见,恰恰因为他们是系统运转的默认背景:他们数以百万计、无处不在,却在统计上模糊、在叙事中缺席。你只在被他们管理、或他们出事时,才会想起他们存在(↗ M2 权力临时工化 / ↗ M5 缓冲垫)。

M2 · 权力的临时工化

本片核心机制

本片核心机制——把最容易引发冲突的治理/执法末梢,外包给无编制、无完整保障、可随时切割的临时人员,既降低成本,又转移问责。这是 GY-05「管理外包化」(↗ GY-05 L3/L4)在治理领域的同构版:平台用外包骑手保护正式员工,体制用编外治理者保护编制权威。

三重功能合一:降成本 · 扩触达 · 转问责

① 降成本编外薪资远低于编内、无编制福利——用最低人力成本撑起治理网络。
② 扩触达用低成本人力把治理网络铺到每个网格——国家以最低成本触达社会末梢的实际办法。
③ 转问责出事时编外是第一责任人/背锅层,编制权威被隔离保护——「临时工」身份的制度功能之一就是充当问责的可切割缓冲。

外包逻辑的同构:平台 ↔ 体制

市场版 · 平台外包(↗ GY-05 L4)
「这不是我的员工,是合作伙伴」

平台用一层身份隔离(法律套娃)把责任和风险下推给外包骑手——保护正式员工与平台主体,把权威和保障上收。

≅
治理版 · 体制外包(本片)
「这不是正式执法者,是辅助人员」

体制用同一层身份隔离把责任和风险下推给编外治理者——保护编制权威,把权威和保障上收。两者结构一致。

问责缓冲器与借权的尴尬

缓冲器舆情事件中「涉事人员是临时工/辅警」的经典回应——事一闹大,切割临时工即可隔离体制(↗ watch W-07 背锅事件)。
借权的尴尬编外治理者执行的是国家权力(巡查、劝导、采集、执法辅助),却不具备完整执法主体资格——权责不对等:有执行之责,无执法之名,无保障之实。
治理成本的精算把冲突最密集的末梢做成可切割的缓冲层

权力的临时工化是治理成本的精算——把冲突最密集的末梢做成可切割的缓冲层,体制既省了钱,又留了退路。编外治理者因此处在一个荒诞的位置:他们行使着国家的权力,却随时可能被国家当作「临时工」切割(↗ M3 双轨 / ↗ M5 缓冲垫)。

M3 · 同工不同酬

编内编外的体制内双轨

编外治理者与编内人员同岗同责却不同酬、不同保障——这是体制内部完整复制的双轨制(↗ GY-07 B4 编内外落差 / GY-05 三重身份的体制版):同一个办公室、同一项工作,编内是「债主」、编外是「零工」。体制内的围墙不止一道。

编内 vs 编外:一道看不见的玻璃墙

墙内 · 编内
「债主」· 刚兑分区(↗ GY-07)

编制福利、晋升通道、刚兑保障——更多统筹/管理;离权力近,也离保障近。财政紧缩时受保护的一侧。

⟂
墙外 · 编外
「零工」· 可切割缓冲

同工不同酬、福利不及、晋升狭窄或封闭——承担最繁重最直接面对群众的一线工作;离权力最近(每天执行它),离保障最远(随时被切割)。

双轨的结构性:落差 · 玻璃墙 · 倒挂 · 缓冲

待遇落差编外薪资普遍偏低(网格员月薪约 3700 量级)、福利保障不及编内、晋升通道狭窄或封闭——同工不同酬是结构性的,不是个案。
身份玻璃墙编外转编内通道极窄(少数定向招录),多数长期「卡」在编外身份——「类体制」的归属感 + 非体制的待遇 = 最尴尬的中间态(↗ GY-07 编外镜像)。
强度倒挂编外承担最繁重、最直接面对群众的一线(入户、巡查、调解、处置),编内更多统筹——活最多的人,待遇最低、最易背锅(↔ GY-17 越关键越不可见 / GY-05 越关键越无地位 的治理版)。
刚兑缓冲编外是体制用来保护编内刚兑的缓冲垫——财政紧缩时(↗ GY-07 B5/GY-01),编外是第一被清退的层(↗ GY-07 W-04 编外清退)。
体制的零工干着最重的活,拿着最薄的酬,背着最先的锅

体制内的围墙不止一道——编内编外之间,还有一道看不见的玻璃墙。编外治理者站在墙的尴尬一侧:离权力最近(每天执行它),离保障最远(随时被切割)。他们是体制的零工,干着最重的活,拿着最薄的酬,背着最先的锅(↗ M2 临时工化 / ↗ M5 缓冲垫)。

M4 · 上面千条线,下面一根针

基层超载

「上面千条线,下面一根针」——上级各条线的任务、考核、台账全部压向基层这「一根针」(网格员/社区),形成基层超载;编外治理者是这根针的针尖,承接全部下压的行政负荷,是形式主义与基层减负悖论的承受端(↗ GY-07 B6 不出错优先的基层版)。

千条线下压 · 一根针超载

千条线下压各部门、各条线的任务(综治、防疫、信访、统计、创卫、安全、宣传)全部下派到网格——基层成为所有上级任务的最终落点。
一根针超载网格员/社区工作者同时对接十几个条线,填不完的台账、应付不完的检查、走不完的访——留痕主义(↗ GY-07 B6)把基层拖入「做事不如证明做事」的内卷。
减负悖论「基层减负」年年喊,基层负担年年增——减负文件本身又成为一项新任务;编外治理者是这个悖论的肉身承受者。

千条线 → 一根针:负荷下压示意

防疫三年:缓冲垫功能用到极致

毛细血管疫情期间网格员/社工/志愿者承担了海量一线工作(排查、值守、配送、管控)——是防控的毛细血管。
损耗与冲击也承受了巨大的身心损耗与干群矛盾的直接冲击——三年把这个人群的「缓冲垫」功能用到极致,也暴露了其无保障的脆弱(↗ M5 第一承接面)。
系统超载的减震器,自己却没有减震承接了下压负荷,却没承接配套的权力、保障与免责

基层治理的全部重量,最终压在一根没有编制的针尖上。上面每增加一条线,针尖就多扎进一分肉里。编外治理者承接了整个行政体系下压的负荷,却没有承接负荷所应配的权力、保障与免责——他们是系统超载的减震器,自己却没有减震(↗ GY-07 B6 / ↗ M5 双向夹击)。

M5 · 政治形态学

缓冲垫的双向夹击

编外治理者处在「体制与社会之间」的结构性夹缝——对上要完成体制的考核,对下要直面群众的矛盾,是干群冲突的第一承接面(背锅层),又是组织化潜能受抑(半体制身份)的沉默人群;其稳定性建立在编制崇拜(盼转正)与就业稀薄(没退路)的双重绑定上。

双向夹击 · 第一承接面 · 组织化受抑

双向夹击对上承接千条线的考核压力,对下承接群众的矛盾投诉——夹在中间,两头受气;执法/管理时是「国家的人」,背锅时是「临时工」。
第一承接面社会矛盾(拆迁、纠纷、投诉、执法冲突)先打到这一层——他们是体制的「矛盾防火墙」,把冲突挡在编制权威之外(↗ GY-02 组件三安全治理的人力底座)。
组织化受抑半体制身份 + 盼转正的期待 + 被吸纳的工会——既不会也不敢集体行动:抗议等于断送转正希望;其不满只能以离职、躺平、消极执行(↗ GY-07 B6)表达。

与体制内青年的接口

镜像下层编外治理者是「体制内青年」(↗ GY-07)的镜像下层——同样年轻、同样在体制边缘,一个在编内盼晋升、一个在编外盼转编;两者共同构成基层治理的青年人力底座。
最稳定的不稳定对上不敢、对下不能,稳定来自没有选择

编外治理者是体制精心设计的矛盾防火墙——把干群冲突挡在编制之外,让真正的权威永远隔着一层「临时工」面对群众。他们对上不敢、对下不能,被编制崇拜和就业稀薄两条绳绑在缓冲垫的位置上:盼着转正,所以忍着;没有退路,所以留着。这是最稳定的不稳定——稳定来自没有选择(↗ GY-02 安全治理 / ↗ M6 形态推演)。

M6 · 形态推演

三态 · α 规范化中维持 / β 财政清退 / γ 职业化vs临时化两极

基层治理末梢的演化路径,按概率拆成三态。三态共享同一个起点(数百万编外治理者、权力临时工化、同工不同酬双轨、一根针超载、缓冲垫的双向夹击),分岔点在于:编外身份会否被规范化、财政会否触发清退、编外大军内部会否分化为职业化与临时化两端。

形态 α · 基准 · 规范化中维持(概率最高)

社区工作者职业化/规范化推进(2024 中办国办意见)、「多员合一」整编、待遇小幅改善,但编外身份与同工不同酬的基本结构维持;缓冲垫功能延续。三态中概率最高(↗ W-01/W-04)。

形态 β · 压力 · 财政清退

地方财政恶化(↗ GY-07 B5/GY-01)使编外治理者成为第一被清退/缩编的层——基层治理人力收缩与治理任务不减的矛盾激化;标志:成规模的编外清退与基层「人少事多」的治理空转(↗ W-03)。

形态 γ · 分化 · 职业化 vs 临时化两极

社区工作者向「准职业化」(薪酬体系、职业发展、部分入编)演进,而辅警/协管等仍停留「临时化」——编外治理大军内部分化为「被规范化的」与「被临时化的」两端;与基层治理的数字化(网格化平台、AI 辅助)叠加重塑人力结构(↗ W-04/W-08)。

总判词 · 借权代理进程 基层治理末梢是 China OS 的借权代理进程——持一枚临时授权令牌执行国家权力,却没有永久账户;所有从社会抛上来的矛盾由它第一个 catch,而它本身随时可被 kill、且出事先背锅。
